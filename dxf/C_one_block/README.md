## Original prototype description

Both MECH and STR merged into a single `OVERLAY_DRAWING` block:
- All MECH entities (red, at original coords)
- All STR entities (blue, transformed to MECH coords)

Modelspace has exactly **one INSERT** at the origin.

## Files in this prototype

| File | Purpose |
|---|---|
| `fit_transform.py` | Same fit logic as A — derives `transform.json` from gridlines |
| `overlay_1block.py` | Pre-scales STR + transforms entities, wraps everything in `OVERLAY_DRAWING` block, saves `TP-104 OVERLAY_C.dxf` |
| `transform.json` | Generated by `fit_transform.py` |
| `TP-104 OVERLAY_C.dxf` | Generated. 1 INSERT at modelspace. |

## Original usage (legacy)

```bash
cd C_one_block
python3 fit_transform.py     # step 1
python3 overlay_1block.py    # step 2
```

## Migrate to the canonical implementation

```bash
cd ../../C/
./run.sh
```

The canonical script (`../../C/scripts/overlay.py`) is functionally
identical but uses self-locating paths and the DWG fallback chain.
