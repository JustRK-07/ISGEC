## Original prototype description

Each drawing is wrapped in its own block:
- `MECH_DRAWING` block — all MECH entities at original coords
- `STR_DRAWING` block — all STR entities at original STR coords

The gridline-derived affine lives in the `STR_DRAWING` INSERT's
`(insert, xscale, yscale)` — no per-entity transform needed. Modelspace
has 2 INSERTs.

## Files in this prototype

| File | Purpose |
|---|---|
| `fit_transform.py` | Same fit logic as A — derives `transform.json` from gridlines |
| `overlay_2block.py` | Wraps MECH in `MECH_DRAWING` block, wraps STR in `STR_DRAWING` block (with affine on the wrapper INSERT), saves `TP-104 OVERLAY_B.dxf` |
| `transform.json` | Generated by `fit_transform.py` |
| `TP-104 OVERLAY_B.dxf` | Generated. MECH red + STR blue, 2 INSERTs at modelspace |

## Original usage (legacy)
