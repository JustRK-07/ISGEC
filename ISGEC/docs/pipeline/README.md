# ISGEC Pipeline — TP-104 Conveyor Overlay

> **Three self-contained overlay strategies** that align two huge engineering drawings via labeled grid bubbles, with sub-unit precision.

This folder documents the **Python pipeline scripts** that live in `ISGEC/A/`, `ISGEC/B/`, and `ISGEC/C/`. Each subdirectory is a self-contained pipeline that takes the same two source drawings (`TP-104 MECH GA` + `TP-104 STR GA`) and produces a **structurally different** superimposed DXF.

The pipeline has **3 stages**: clean → fit → overlay. Each `A/`, `B/`, `C/` directory contains the same first two stages, with the third differing in **structure, editability, and color policy**.

## ⚡ Quick start

```bash
# 1. Run the multi-approach driver (uses pre-cleaned DXFs in dxf/)
cd ISGEC/
python3 run_to_dxf.py

# Output:
#   dxf/superimposed.dxf      ← canonical (approach A)
#   dxf/superimposed_A.dxf    ← per-entity, original colors
#   dxf/superimposed_B.dxf    ← 2-block, forced red/blue
#   dxf/superimposed_C.dxf    ← 1-block, forced red/blue
```

```bash
# Or run a single strategy:
cd A/   && ./run.sh
cd B/   && ./run.sh
cd C/   && ./run.sh
```

```bash
# Verify all three:
cd ISGEC/
python3 verify_all.py 3
```

```bash
# Pixel-level overlap check:
python3 check_overlap.py

# Visual rendering:
python3 render_structure.py    # lime X markers show wrapper INSERTs
python3 render_all.py          # side-by-side composite
```

## 🎯 At a glance

| Approach | Modelspace entities | Wrapper INSERTs | TP104-A residual | Editability | Color policy |
|---|---:|---|---:|---|---|
| **A** per-entity | 2,242 | 0 | < 2.34e-7 DXF units | **HIGHEST** | **Original colors preserved** |
| **B** 2-block | 2 INSERTs | MECH_DRAWING + STR_DRAWING | < 2.34e-7 DXF units | MEDIUM | **Forced red (MECH) / blue (STR)** |
| **C** 1-block | 1 INSERT | OVERLAY_DRAWING | < 2.34e-7 DXF units | LOW | **Forced red (MECH) / blue (STR)** |

All three use the **same affine** derived from labeled gridlines (TP104-A/B/C/D × 1/2/3):

```
x_m = 1.000000 · x_s + 208379.8605
y_m = 1.000000 · y_s + -179584.5241
```
